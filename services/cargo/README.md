# Cargo service

Tessera **cargo / luggage / vehicle ops** PHP module.

| | |
|--|--|
| Path | `services/cargo` |
| URL | `/cargo/` |
| Database | `cargo` (dump: `database/cargo.sql`) |
| UI | Dashonic + Tickets \| Cargo \| Accounts |

## Local

```text
XAMPP: htdocs/cargo → services/cargo
URL:   http://localhost/cargo/
```

`connect.php` → database `cargo` via `SR_CARGO_DB` (default `cargo`).
